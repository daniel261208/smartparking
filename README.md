# חניון חכם 🚗

## על הפרויקט

חניון חכם הוא מערכת לניהול חניון, שנבנתה באמצעות Docker Compose.

המערכת כוללת:

- **שרת אינטרנט (Nginx):** מציג את לוח הבקרה של החניון.
- **שרת אחסון (Apache):** מאחסן ומציג תמונות של כלי רכב.
- **מחשבון מחיר חניה:** מחשב את מחיר החניה בהתאם למספר השעות שהרכב חנה.

## מבנה הפרויקט

```text
smartparking/
├── web/
│   ├── index.html
│   ├── style.css
│   └── Dockerfile
├── storage/
│   ├── images/
│   └── Dockerfile
├── .github/
│   └── workflows/
│       └── docker-build.yml
└── docker-compose.yml
```

## כיצד להפעיל את המערכת?

יש לוודא שתוכנת Docker Desktop פועלת.

יש לפתוח את הטרמינל בתיקיית הפרויקט ולהריץ את הפקודה הבאה:

docker compose up -d --build

לאחר מכן, יש לפתוח את לוח הבקרה בדפדפן:

http://localhost:8081

תמונות כלי הרכב מוצגות באמצעות שרת האחסון בכתובת:

http://localhost:8080/images/

שירותי Docker

Web: שרת Nginx הפועל בפורט 8081 ומציג את לוח הבקרה.

Storage: שרת Apache הפועל בפורט 8080 ומספק את תמונות כלי הרכב.

Volume: מחבר בין תיקיית התמונות המקומית storage/images לבין שרת Apache, כדי שהתמונות יישמרו גם לאחר הפעלה מחדש של הקונטיינרים.

GitHub Actions

תהליך אוטומטי באמצעות GitHub Actions בונה את שתי תמונות ה-Docker בכל פעם שמעלים שינויים למאגר בענף main.

רכיב ייחודי בפרויקט

בלוח הבקרה קיים מחשבון לחישוב מחיר החניה.

מחיר החניה הוא 10 שקלים לכל שעת חניה. המחשבון מקבל את מספר השעות ומציג את המחיר לתשלום.
